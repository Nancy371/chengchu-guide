# 真实自测记录

## 持续购买任务版本（2026-09-28）

本版新增独立 `PurchaseTask`，把购买目标、预算回答状态、待问问题、已展示 SKU 和本轮动作从普通用户事实中分离。每轮按“更新任务 → 重算六款商品 → 找一个必要缺口 → 授权结果”推进。个性化推荐必须先取得预算或“不限预算”；问价与政策插话保留原任务；换目标重新确认预算；请求其他推荐时不重复已展示商品。

本地 Worker + D1 完成四轮实测：`我是油皮，想买洗面奶 → 预算200 → 我喜欢玫瑰香 → 还有其他推荐吗`。实际依次追问预算、追问香味、推荐 P102 并把 P101 作为备选，最后返回 `unavailable`，说明符合当前目标和条件的商品已经展示完；玫瑰香仅保存为用户偏好，没有被写成任何商品香型。依据轨迹显示每次检索都检查六个 SKU。另有完整测试覆盖礼盒消歧、拒答预算仅列价格、目标切换清空旧预算、插入问价不增加追问次数、四轮低风险含糊回答、安全拒答和并发迟到结果。

自动化结果：123 项测试、50/50 条固定评测、TypeScript 类型检查、ESLint 和 Vinext 生产构建通过。本地 Worker 未配置模型密钥，D1 多轮验证走确定性降级；公网真实 DeepSeek 链路在本次发布后单独验收。

## 必要信息澄清版本（2026-09-28）

本版将同一购买目标下的低风险必要问题上限设为四轮。已经完成强制安全、资格和预算检查后，只有会改变候选资格或两款商品取舍的信息才继续问；明确当前不适直接停推，安全表述不清则在再次选购时继续核实。用户明确不愿回答时，当轮不再追问。两款合格商品仍无法取舍时，返回 `comparison_only`：分别列出已核实的商品事实和价格，不指定主推，也不计算组合总价。

本地 Worker + D1 API 实测：`想买洗面奶 → P101 多少钱 → 还可以 × 4`。问价轮准确回答 P101 ¥169，保留先前问题且不计入模糊回答次数；四次含糊回答后返回 `comparison_only`，分别给出 P101 ¥169、P102 ¥149，推荐卡为空，总价为空。另一会话输入 `皮肤有点不舒服，想买洗面奶 → 不方便说 → 还是想买洗面奶`：拒答轮返回 `unavailable`，没有推荐或问题；再次选购时仍要求确认当前不适。刷新恢复、品类切换、并发安全输入和幂等重试一并通过本地 API 脚本。

自动化结果：113 项测试、50/50 条固定评测、TypeScript 类型检查及 Vinext 构建通过。本地 Worker 未配置模型密钥，上述 D1 实测验证的是 API、状态、授权与确定性降级链路，**不代表本版真实 DeepSeek 或公网部署已验收**。此前公网真实模型记录属于旧版。

## 受控 Planner 版本（2026-09-28）

本地 Worker + D1 的真实三轮会话依次输入 `我是干皮，预算200，想买洗面奶`、`预算改成100`、`没有刺痛，但皮肤破损`。实际动作依次为 `recommend`（P101/P102 两个备选）、`budget_conflict`（两款洁面均超过 ¥100）、`safety`（零推荐）。三个结果均显示 `APPROVED` 授权，输入／状态版本依次为 1/1、2/2、3/3。本地未配置模型密钥，第一轮 Planner 记录 `model_not_configured` 并经确定性回退；此记录不证明真实模型链路已通过。

95 项自动测试与 50/50 条冻结导购评测通过；TypeScript 类型检查和 Vinext 生产构建通过。新增测试覆盖：多品类检索前不得结束规划、重复动作和 Planner 异常、越权 Final Reasoner 提案被拒绝并重新授权回退，以及迟到 Planner/Reasoner 不能覆盖新的安全输入。

第 9 版公网测试发现 Planner 的非授权说明字段未满足本地格式要求，第一轮走确定性回退。第 10 版将这些说明在本地规范化后，使用公网 API 和生产 Secret 重新完成三轮真实模型测试：

1. `我是干皮，预算200，只想买洗面奶`：Planner 依次执行 `search_products → compare_products → finalize`，三步均通过 ActionPolicy；Final Decision Reasoner 实际调用并提出 P101 + `catalog:P101`，最终授权 `APPROVED`，推荐 P101 ¥169，无降级。
2. `预算改成100`：返回 `budget_conflict`，推荐清空，最终授权 `APPROVED`；表达模型提案未过本地校验，回退模板。
3. `没有刺痛，但皮肤破损`：返回 `safety`，推荐清空，最终授权 `APPROVED`，无需等待 Planner 或 Renderer。

三轮的输入／状态版本依次为 1/1、2/2、3/3。公网 API 已验证真实模型链路和安全改口；浏览器中的依据抽屉自动检查在刷新时超时，界面展示仍待人工复核。

## 情绪、拒绝与习惯记忆

- 输入 `选半天了越看越烦，就想简单一点，只看洁面`：识别当前明确的烦躁和精简诉求，先承接“选来选去容易累”，只保留一个会改变洁面选择的问题。
